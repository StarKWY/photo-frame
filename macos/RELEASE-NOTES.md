# 留白 1.0.0

macOS 原生版。网页版功能全都在，装在本地跑，照片一个字节都不出本机。

## 下载

| 文件 | 说明 |
|---|---|
| `留白-1.0.0-macos-universal.zip` | 通用二进制，Intel 与 Apple Silicon 通用，1.2 MB |

## 系统要求

macOS 14.0（Sonoma）或更高。

## 安装

1. 下载 zip，双击解压，得到 `留白.app`
2. 把它拖进「应用程序」文件夹
3. **第一次打开必须右键 →「打开」**，在弹出的对话框里再点一次「打开」

> 第 3 步不是可选项。这个 App 用的是本地自签名（ad-hoc），没有 Apple 开发者证书，直接双击会被系统拦下并提示"无法打开，因为 Apple 无法验证开发者"。
> 右键打开只需要做一次，之后双击就正常了。
>
> 如果右键打开仍然被拦，可以在「系统设置 → 隐私与安全性」页面底部找到拦截提示，点「仍要打开」。
> 也可以在终端里执行一次：`xattr -dr com.apple.quarantine /Applications/留白.app`

## 功能

- 照片加留白边框、自定义边距与比例
- 参数水印（机型、镜头、光圈、快门、ISO、焦距、拍摄日期）
- 模板预设
- HEIC 直接导入（走系统原生解码，不联网）
- 批量导出 ZIP
- 跟随系统深浅色主题

## 隐私

- 全程本地处理，App 内建断网拦截规则，只允许加载本地资源
- 内置网页版代码，不访问任何外部地址
- 照片不上传、不缓存到云端

## 已知限制

- 未做 Apple 公证（notarization），所以首次打开需要右键
- 仅 macOS 14+，更早的系统不支持
- 安卓/iPhone 请用网页版或添加到主屏幕的 PWA
